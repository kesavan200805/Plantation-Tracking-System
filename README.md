# Plantation Tracking System

A Java console-based application for managing and tracking plantation records.

## Features

- Add Plant
- View Plants
- Search Plant
- Update Plant
- Delete Plant
- Exit

## Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming

## Project Structure

- `Main.java` - Main application and menu operations
- `Plant.java` - Plant model class

## How to Run

1. Clone the repository
2. Compile the Java files
3. Run `Main.java`
